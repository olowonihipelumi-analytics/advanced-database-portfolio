# Library Management System

## Project Overview

This project implements a relational database for a Library Management System as part of MIT 8103 Advanced Database Systems.

## Objectives

- Design a relational database for members, books, and borrowing transactions.
- Implement primary keys, foreign keys, and integrity constraints.
- Demonstrate relationships between database tables.
- Use SQL queries to retrieve and analyse borrowing records.
- Document the database design and normalisation.

## Technologies

- Microsoft SQL Server
- SQL Server Management Studio 22
- diagrams.net for the ER diagram

## Database Tables

- Members
- Books
- Loans

## Project Files

The `portfolio-1-database-design` folder contains the SQL script, ER diagram, documentation, and implementation screenshots.

## Implementation

The database was implemented in Microsoft SQL Server. Sample records were inserted into each table, and SELECT and JOIN queries were executed to verify the relationships and retrieve borrowing information.
