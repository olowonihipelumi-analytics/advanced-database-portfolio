# Portfolio 4: NoSQL and Advanced Data Models

## Case Study
Library Management System

## Database Platform
MongoDB Community Server

## Interface
MongoDB Compass

## Overview
This portfolio demonstrates the implementation of a document-oriented NoSQL database using MongoDB.

## Implementation
- Created the LibraryManagementNoSQL database.
- Created Books, Members and Loans collections.
- Inserted BSON documents.
- Executed document filtering queries.
- Demonstrated referencing and embedding.
